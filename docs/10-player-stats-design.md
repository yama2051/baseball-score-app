# 選手成績入力・計算 設計書

## 1. 概要

試合を選択し、登録済み選手ごとの打撃・投手成績を入力する。試合別の成績を保存し、`PlayerStatsCalculator` で選手別通算値と率を表示する。

## 2. コンポーネント構成

- `PlayerStatsManager`: 試合選択、選手ごとの成績入力、入力検証、保存
- `PlayerStatsCalculator`: 選手別の通算成績テーブルを表示
- `PlayerSeasonStats`: 複数試合の記録を集計し、打撃率・投手指標を計算
- `PlayerList`: 現在の選手一覧と試合一覧を成績管理へ渡す

## 3. 成績データ

各レコードは `gameId` と `playerId` の組で試合と選手を識別する。

### 打撃記録

- 打数、安打、二塁打、三塁打、本塁打、打点
- 四球、三振、死球、犠牲フライ

### 投手記録

- 投球アウト数、自責点、奪三振、被安打、与四球

投球アウト数は投球回に換算する。画面では野球表記を使い、末尾 `.1` は1/3回、`.2` は2/3回を表す。

## 4. 計算ロジック

`PlayerSeasonStats` は試合別記録を合計し、以下を算出する。

- 打率 = 安打 ÷ 打数
- 出塁率 = (安打 + 四球 + 死球) ÷ (打数 + 四球 + 死球 + 犠牲フライ)
- 塁打 = 安打 + 二塁打 + (三塁打 × 2) + (本塁打 × 3)
- 長打率 = 塁打 ÷ 打数
- 防御率 = 自責点 × 27 ÷ 投球アウト数
- WHIP = (被安打 + 与四球) × 3 ÷ 投球アウト数

分母が0の場合は数値を表示せず「—」とする。率の表示桁は打率・出塁率・長打率が小数第3位、防御率・WHIPが小数第2位。

## 5. 入力検証と保存

- 各成績は0以上の整数とする
- 安打数は打数以下
- 二塁打・三塁打・本塁打の合計は安打数以下
- 試合別の全選手分を保存ボタンから保存する
- 保存キーは `baseball-score-app-player-game-stats`
- 入力した試合別成績と集計値をブラウザーの `localStorage` に保持する

## 6. データフロー

```text
App.games ─┐
           ├─> PlayerList ─> PlayerStatsManager ─> localStorage
players ───┘                         │
                                     └─> PlayerStatsCalculator
                                           └─> PlayerSeasonStats
```

## 7. 設計意図

- 入力、計算、表示の責務を分離する
- 計算ロジックを `PlayerSeasonStats` にまとめ、UIから独立させる
- 計算結果の表示を専用の `PlayerStatsCalculator` コンポーネントに分離する
- 試合IDと選手IDで管理し、試合別の再編集と複数試合の通算集計を可能にする
