# GameScore 設計書

## 1. 概要

`GameScore` は1試合のイニング別得点を保持し、チーム別合計と勝敗を計算するドメインモデルである。React コンポーネントから独立させ、表示や入力 UI に集計ルールを持たせない。

## 2. 責務

- ホームとアウェーのイニング別得点を対応付ける
- 各チームの合計得点を提供する
- 合計得点を比較し、勝敗または引き分けを返す

## 3. データモデル

```ts
type InningScore = {
  inning: number
  home: number
  away: number
}
```

`GameScore` は同じ回数のホーム得点配列とアウェー得点配列から生成する。配列長が異なる場合は不正なスコアとして例外を送出する。

## 4. 公開プロパティと操作

- `innings`: 回番号と両チームの得点を持つ読み取り用データ
- `homeTotal`: ホームチームの合計得点
- `awayTotal`: アウェーチームの合計得点
- `getResult(homeTeam, awayTeam)`: チーム名を含む勝敗文字列

同点の場合は「引き分け」、それ以外は合計点の大きいチームの勝ちを返す。

## 5. 利用箇所

- `GameForm`: 入力中のチーム別合計はフォーム値から表示する
- `GameResultList`: `GameScore` を使い、登録済み試合のイニング別得点、合計、勝敗を表示する
- `App`: 試合データを保持し、localStorage へ保存する

## 6. 設計意図

- 得点計算ルールを UI から分離し、再利用と検証をしやすくする
- 試合入力と結果表示が同じドメイン概念を共有できるようにする
- 将来の延長戦や選手成績などの追加時に、試合データの中心モデルとして拡張できる構成にする
